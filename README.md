# kidneyshield-privacy

Public hosting for the privacy policy and terms of **KidneyShield**
(`com.lacaprara.kidneyshield`), an Android kidney stone prevention companion.

Live at **<https://l3g1t50.github.io/kidneyshield-privacy/>** — the URL for the
Google Play store listing. Terms are at
<https://l3g1t50.github.io/kidneyshield-privacy/terms.html>.

This repo exists only because free GitHub Pages requires a public repository and
the app's source repo is private. It contains no app code.

## Editing

`docs/privacy-policy.html` and `docs/terms.html` in the app repo are the canonical
source of this text. Edit them there first, then mirror the change here. `index.html`
and `privacy-policy.html` are identical copies of the policy, because the terms page
links to `./privacy-policy.html`. Bump the effective date on any change.
